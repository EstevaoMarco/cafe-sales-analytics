O CSV original é redistribuído com esta atribuição; o nome local recebeu o prefixo
`1.`. Os dados tratados são uma adaptação: conversão de tipos, recuperação aritmética,
inferência limitada por preços, padronização de categorias e tratamento de datas,
conforme explicado no README e no notebook. O Power BI traduz categorias de ausência
para inglês e contém os dados tratados em modo Importação.

Os dados adaptados, inclusive os incorporados ao relatório, são disponibilizados
sob a mesma licença CC BY-SA 4.0. Não há endosso deste projeto pelo publicador original.
Esta atribuição dos dados não equivale a atribuir uma licença de software a todo o
código do repositório.
